crypto-broker-operator was deployed as release "{{ .Release.Name }}".

The operator runs in namespace "{{ .Values.namespace.name }}" and watches
CryptoBroker resources cluster-wide. When a CryptoBroker is created, it injects
the crypto-broker-server sidecar ({{ .Values.serverImage }}) into the target
Deployment named in spec.targetDeployment.

Check the operator:
  kubectl get pods -n {{ .Values.namespace.name }} -l app.kubernetes.io/name=crypto-broker-operator
  kubectl logs -n {{ .Values.namespace.name }} deployment/crypto-broker-operator

List CryptoBroker resources:
  kubectl get cryptobrokers -A

NOTE: Helm installs CRDs from the crds/ directory on first install only. It does
not upgrade or delete them. To update the CryptoBroker CRD later, apply it
manually:
  kubectl apply -f charts/crypto-broker-operator/crds/cryptobroker-crd.yaml
